# Project notes — Nature Sacred website

## Language rules (apply to every page)

- **Nature Sacred does not "build" Sacred Places.** We work with communities to lead
  them through a distinct, community-led process — with our guidance. Avoid "we build /
  we built / the build / how we build." Prefer: "communities create," "we guide the
  process," "we work alongside," "designed with," "comes to be."
- **Firesoul™** carries the trademark on its FIRST use in body copy on each page
  (superscript ™, `<sup style="font-size:0.55em; font-weight:700; vertical-align:super;
  line-height:0; margin-left:1px;">™</sup>`). Plain "Firesoul/Firesouls" everywhere
  after that, and never in nav, footer links, or menu labels.
- Each page is part of a larger site. Don't re-explain what a Sacred Place, a Firesoul,
  or the bench + journal is on every page — assume the visitor has that context from
  elsewhere on the site unless the page is specifically about it.
