# Our Design Process — page handoff

Open `index.html` in a browser. Everything it needs is in this folder.

## Contents
- index.html — the page (identical to "Our Design Process -3.dc.html")
- support.js — runtime that renders the page template
- image-slot.js — drag-and-drop image placeholder component
- assets/ — every image the page references

## Fonts
Loaded from Google Fonts at runtime: Nunito (400/600/700/800), Lora (italic, editorial), Caveat (used sparingly).
